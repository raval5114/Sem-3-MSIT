# Architecture & Design Specifications

## 1. Security Architecture & Filter Chain

Spring Security is configured in `SecurityConfig.java` with stateless execution.

### Request Flow Pipeline
1. **HTTP Request Arrival**: Client sends request with optional `Authorization: Bearer <jwt_token>` header.
2. **`JwtAuthFilter` execution** (`OncePerRequestFilter`):
   - Checks for `Authorization` header starting with `Bearer `.
   - Extracts username (email) using `JwtService.extractUsername(token)`.
   - Validates token against `UserDetails` via `JwtService.validateToken(token, userDetails)`.
   - Populates `SecurityContextHolder.getContext().setAuthentication(authToken)`.
   - Passes request down the chain.
3. **Endpoint Authorization Rules**:
   - `/auth/welcome`, `/auth/addNewUser`, `/auth/generateToken` → **Public** (`permitAll()`)
   - `/auth/user/**` → Requires authority `ROLE_USER`
   - `/auth/admin/**` → Requires authority `ROLE_ADMIN`
   - All other requests → Must be authenticated (`authenticated()`)

## 2. Database Model & Persistence

### Database Configuration (`application.properties`)
- **JDBC URL**: `jdbc:mysql://localhost:3306/springseclearning?createDatabaseIfNotExist=true`
- **Username**: `root`
- **Password**: *(empty)*
- **DDL Mode**: `update` (Hibernate creates/updates missing tables)

### Entity Definition: `UserInfo`
- **Table Name**: `user_info` (auto-generated by Hibernate)
- **Primary Key**: `id` (`INTEGER`, Auto Increment)
- **Fields**:
  - `id`: `int` (Primary Key)
  - `name`: `String`
  - `email`: `String` (Used as the username for authentication)
  - `password`: `String` (BCrypt encoded)
  - `roles`: `String` (Comma-separated roles, e.g. `ROLE_USER,ROLE_ADMIN`)

### Repository Layer
- **`UserDetailsRepository`**:
  - `findByemail(String email)`: Fetches user by email address.
  - `findByUsername(String username)`: Secondary finder signature.

## 4. Services Breakdown

1. **`JwtService`**:
   - Responsibilities: JWT creation (`generateToken`), claim extraction (`extractUsername`, `extractAllClaims`), expiration validation (`isTokenExpired`), and signature validation (`validateToken`).
   - Secret key: Generated via `Keys.secretKeyFor(SignatureAlgorithm.HS256)`.

2. **`UserInfoService`**:
   - Implements `UserDetailsService`.
   - `loadUserByUsername(String username)`: Loads `UserInfo` from `UserDetailsRepository` and wraps it in `UserInfoDetails`.
   - `addUser(UserInfo userInfo)`: Encodes password via `PasswordEncoder` before saving.

3. **`UserInfoDetails`**:
   - Implements `UserDetails`.
   - Splits comma-separated roles in `UserInfo` into `GrantedAuthority` list (`SimpleGrantedAuthority`).
